# mWriter

mWriter is a minimalist notepad app made in Python using Qt.

<img width="1868" height="1056" alt="image" src="https://github.com/user-attachments/assets/6a9fbb37-9ea1-4afa-a46a-81f5957bd215" />


## Features

- Word count recognizes space, apostrophe and hyphen as word differentiator.
- Open and save files
- Button to open the nerd fonts cheat sheet. Ctrl + Shift + N also opens it.
- Font: Iosevka Term Nerd Font
